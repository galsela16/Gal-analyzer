# אנלייזר ספקטרום · RTA

אפליקציית PWA לניתוח סאונד בזמן אמת מהמיקרופון:

- **1/3 אוקטבה (ISO)** — 31 פסים בתקן, מ־20Hz עד 20kHz.
- **ווטרפול / ספקטרוגרמה** — מפת תדר־זמן נגללת.
- **גלאי פידבק** — מסמן תדרים צרים, בולטים ומתמשכים בזמן אמת ומציע איפה לחתוך ב־EQ.
- **מד עוצמה (Level)** — מדידת RMS בזמן אמת עם peak hold, וכיול ל־dB SPL.
- **עובד גם אופליין** ומותקן כאפליקציה (PWA).

## קבצים
```
index.html               האפליקציה
manifest.webmanifest     הגדרות PWA
sw.js                    Service Worker (אופליין)
icons/                   אייקונים
```

## העלאה ל־GitHub Pages
1. צור ריפו חדש (למשל `rta`) והעלה אליו את כל הקבצים.
2. Settings → Pages → Branch: `main`, Folder: `/root` → Save.
3. הכתובת תהיה `https://<שם-משתמש>.github.io/rta/`.
4. פתח בטלפון → תפריט הדפדפן → "הוסף למסך הבית" כדי להתקין.

> חובה HTTPS (GitHub Pages נותן את זה אוטומטית) — אחרת הדפדפן לא ייתן גישה למיקרופון.

## שימוש
1. לחץ "הפעל מיקרופון" ואשר הרשאה.
2. החלף בין "1/3 אוקטבה" ל"ווטרפול" למעלה.
3. **רצפת רעש** — מוריד את המדידה מתחת לסף הזה (פחות רעש רקע בתצוגה).
4. **החלקה** — כמה התצוגה "רגועה" (גבוה = חלק יותר, איטי יותר).
5. **Peak Hold** — קווים לבנים ששומרים את השיא בכל פס.
6. **גלאי פידבק** — התראות אדומות עם התדר לחיתוך. **רגישות פידבק** קובעת כמה בולט צריך להיות פיק כדי להיחשב.
7. **מד עוצמה** (הפס למטה) — מציג `dBFS` (יחסי). דפדפן לא נותן SPL אמיתי בלי כיול.

## כיול SPL
מיקרופון בדפדפן מודד ביחס ל־Full Scale, לא SPL מוחלט. כדי לקבל קירוב ל־dB SPL:
1. שים ליד המכשיר מד SPL אמיתי (או אפליקציית SPL מכוילת).
2. נגן רעש קבוע והשווה: אם המד מראה 85dB SPL והאפליקציה מראה `-15 dBFS`, ההפרש הוא 100.
3. גרור את **כיול SPL** ל־`+100` — מעכשיו המספר יוצג כ־`dB SPL≈`.
> זה קירוב שתלוי במיקרופון ובמכשיר, לא מדידה תקנית.

## עדכון גרסה
כששינית קבצים, שנה את `CACHE = 'rta-v1'` ב־`sw.js` (למשל ל־`rta-v2`) כדי שהמכשירים ימשכו את הגרסה החדשה.

## פיצ'רים נוספים (שלב 1)
- **מיצוע** — ממצע את התצוגה לאורך זמן לתמונה יציבה (למדידת חדר/PA).
- **הקפא** — מצלם את העקומה הנוכחית ומציג אותה כקו כתום מעל החי, להשוואת לפני/אחרי (A/B). לחיצה שנייה מנקה.
- **PNG** — שומר צילום של התצוגה הנוכחית.
- **CSV** — מייצא טבלת תדר→dB של כל הפסים (לפתיחה באקסל).
> שינוי רזולוציה מנקה הקפאה קיימת (כי מספר הפסים משתנה).

## פיצ'רים נוספים (שלב 2)
- **שקלול SPL** — כפתור שמחליף בין Z (ללא שקלול), A (dBA) ו־C (dBC), החישוב התקני של מדי SPL.
- **Leq** — ממוצע אנרגיית הרמה לאורך זמן (למגבלות רעש באולמות). **Max** — שיא שנשמר.
- **אפס Leq** — מאפס את המדידה המצטברת.
- **מקור קלט** — בחירת מיקרופון/כרטיס קול מהרשימה.
- **זום** — גרירה על הגרף בוחרת טווח תדרים ומגדילה אותו. "טווח מלא" או דאבל־קליק חוזר להכל.
> ה־SPL עדיין תלוי כיול (ראה "כיול SPL"). ללא כיול המספרים יחסיים.

## פיצ'רים נוספים (שלב 3)
- **גנרטור אותות** — רעש ורוד / לבן / סינוס (תדר נבחר), יוצא דרך הרמקולים למדידת המערכת. עוצמה מתחילה נמוכה ועולה בהדרגה.
  > ⚠ עוצמה גבוהה מזיקה לרמקולים ולאוזניים — התחל נמוך.
- **עקומת יעד** — קו ייחוס על הגרף (שטוח / House עם באס מוגבר) לכיוונון המערכת לעברו.
- **הצעת EQ מהפידבק** — כל התראת פידבק מציגה גם כמה dB לחתוך ובאיזה Q משוער.

## פיצ'רים נוספים (שלב 4)
- **RT60** — מדידת זמן הדהוד בשיטת רעש מופסק: לחיצה משמיעה רעש ורוד, חותכת אותו, ומודדת את שיפוע הדעיכה. מציג RT60 (T20/T30) וגרף דעיכה. מדידה רחבת־פס ומשוערת — לחדר שקט ועוצמה מספקת.
- **תגובה pink** — תצוגה מפוצה לרעש ורוד: מערכת שטוחה תיראה שטוחה. זו עקומת המגניטודה המעשית של המערכת+חדר (Transfer Function למיקרופון יחיד).
> Transfer Function מלא (פאזה+קוהרנטיות) דורש כרטיס קול עם כניסת ייחוס — לא נכלל.

## דיוק ה־EQ (שדרוג)
- **מדידה מוארכת** — כל מדידה צוברת אנרגיה על פני 5 שניות (יציב הרבה יותר מצילום רגעי).
- **ריבוי מיקומים** — "מדוד מיקום נוסף" בכל נקודה בחדר; ההצעות מבוססות על ממוצע כל המיקומים (מנטרל שיאים/שקעים מקומיים, במיוחד בבאס).
- **כיול מיקרופון** — "טען כיול מיק'" מקבל קובץ טקסט של תדר+dB (פורמט REW/miniDSP), ומנטרל את צביעת המיק'.
> הכי מדויק: מיקרופון מדידה + קובץ כיול + 4–6 מיקומים. מיקרופון טלפון בלי כיול = כיוון גס.
