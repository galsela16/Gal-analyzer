# GAL Analyzer 5.5.41

- Added a polished segmented resolution strip below the display-mode selector.
- Exposed the four canonical RTA resolutions: 1/3, 1/6, 1/12 and 1/24 octave.
- Synchronized the new strip with the existing settings slider, I/O selector and legacy resolution menu.
- Added active, hover, dark-theme and daylight-theme states.
- Reserved dedicated vertical space for the strip on desktop, narrow-window, tablet and phone layouts so it never covers the graph.
- Removed the decorative green/yellow/red strip from the I/O card; it was not connected to a live input measurement and could be mistaken for a permanently full meter.
- Updated version identifiers and service-worker cache busting to 5.5.41.
