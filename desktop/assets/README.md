# Final GAL Analyzer logo

`gal-analyzer-logo-final.jpeg` is the exact 2048×2048 artwork supplied and selected
by the user on October 9, 2026. It supersedes the generated proposals. The original
file is preserved unchanged, including its text, colors, tile and background.

`build-icon.cjs` converts and resizes that artwork into the native ICNS size set.
`prepare.cjs` uses the same artwork for the bundled desktop interface icons.
These are format/size conversions, not a generated redesign or background edit.
